# 📄 Plantilla Oficial de Licitación - LicitAgil

## ℹ️ Información

Esta plantilla es el formato oficial requerido para crear licitaciones en el sistema **LicitAgil**.

## ✅ Requisitos Obligatorios

Para que su licitación sea validada automáticamente, el documento PDF debe incluir las siguientes secciones:

### 1. PORTADA
- Nombre de la licitación
- Departamento solicitante
- Fecha de publicación
- Fecha de cierre

### 2. OBJETIVO Y ALCANCE
- Objetivo principal
- Alcance del proyecto

### 3. REQUISITOS TÉCNICOS Y ADMINISTRATIVOS
- Especificaciones técnicas
- Requisitos administrativos

### 4. CRITERIOS DE EVALUACIÓN
- Tabla de ponderación
- Descripción detallada de criterios

## 🔍 Validación Automática

El sistema LicitAgil utiliza **palabras clave** para detectar estas secciones.  
Asegúrese de usar los títulos proporcionados en esta plantilla.

### Palabras Clave Detectadas por Sección:

**Portada:** portada, nombre, departamento, fecha, licitación, título  
**Objetivo y Alcance:** objetivo, alcance, propósito, finalidad  
**Requisitos Técnicos:** requisitos técnicos, especificaciones técnicas  
**Criterios de Evaluación:** criterios de evaluación, ponderación, calificación

## 📝 Instrucciones de Uso

1. Descargue esta plantilla desde el sistema LicitAgil
2. Complete todas las secciones con su información
3. Exporte/convierta a PDF
4. Suba el PDF al sistema
5. El sistema validará automáticamente el cumplimiento

## ⚠️ Importante

- Use texto seleccionable (no imágenes escaneadas sin OCR)
- Mantenga los títulos de secciones
- Complete todos los campos requeridos
- Tamaño máximo: 2MB

## 🎨 Conversión a PDF

### Opción 1: Markdown → PDF (Recomendado)
Herramientas como:
- [Pandoc](https://pandoc.org/)
- [Markdown PDF (VS Code Extension)](https://marketplace.visualstudio.com/items?itemName=yzane.markdown-pdf)
- Editores online (HackMD, StackEdit, etc.)

### Opción 2: Word/LibreOffice
1. Copie el contenido de esta plantilla
2. Péguelo en Word/LibreOffice Writer
3. Complete los campos
4. Exporte como PDF

## 💡 Consejos

✅ **Sí:**
- Usar los títulos exactos de la plantilla
- Incluir todas las secciones
- Proporcionar información clara y detallada

❌ **No:**
- Cambiar los nombres de las secciones principales
- Omitir secciones obligatorias
- Usar PDFs escaneados sin OCR

Si tiene problemas con la validación, contacte al administrador del sistema.
